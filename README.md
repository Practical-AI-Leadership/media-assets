# Media Assets

Media assets for [Practical AI Leadership](https://practical-ai-leadership.com) published content.

## Structure

```
linkedin/
  week_{NN}/
    {day_prefix}_{type}_{slug}.png
    {day_prefix}_{type}_{slug}.jpg
```

Each LinkedIn post's image is named to match the post draft filename in the content repo (without the `.md` extension).
